# 📖 الباحث في الآيات القرآنية (Quran Researcher)

محرك بحث قرآني متقدم وسريع، مبني باستخدام PHP و MySQL، يوفر أدوات بحث دقيقة وشاملة للباحثين والقراء.

## ✨ المميزات
- **بحث متعدد المستويات**:
  - **بحث بالجذر**: البحث عن جميع مشتقات الكلمة (مثلاً: "كتب" تجد "كتاب", "مكتوب", "يكتبون").
  - **بحث بالكلمة المطابقة**: البحث عن كلمة محددة تماماً.
  - **بحث بجزء من الكلمة**: البحث عن أي كلمة تحتوي على المقطع المدخل.
- **شروط بحث مركبة**: إمكانية دمج عدة شروط باستخدام "و" (AND) أو "أو" (OR).
- **تجاهل التشكيل**: البحث يعمل بمرونة مع النصوص المشكلة وغير المشكلة.
- **تفسير الآيات**: عرض التفسير الميسر للآيات في نتائج البحث.
- **واجهة متجاوبة**: تصميم عصري يعمل على جميع الأجهزة (موبايل، تابلت، ديسك توب).

## 🛠️ متطلبات التشغيل
- PHP 7.4 أو أحدث.
- MySQL 5.7 أو أحدث.
- خادم ويب (Apache, Nginx, أو XAMPP).

## 🚀 طريقة التثبيت والتشغيل

1. **تحميل المشروع**
   ```bash
   git clone [https://github.com/iTarek/Quran-Researcher.git](https://github.com/iTarek/Quran-Researcher.git)
   cd Quran-Researcher
   ```

2. **إعداد قاعدة البيانات**
   - قم بإنشاء قاعدة بيانات جديدة باسم `quran_search`.
   - قم باستيراد ملف `quran_researcher.sql` إلى قاعدة البيانات:
     - عبر phpMyAdmin: اختر قاعدة البيانات > Import > اختر الملف.
     - أو عبر سطر الأوامر:
       ```bash
       mysql -u root -p quran_search < quran_researcher.sql
       ```

3. **إعداد الاتصال**
   - قم بإعادة تسمية ملف `db.example.php` إلى `db.php`.
   - افتح الملف وعدّل بيانات الاتصال لتناسب خادمك:
     ```php
     $host = 'localhost';
     $dbname = 'quran_search';
     $username = 'root'; // اسم المستخدم لقاعدة البيانات
     $password = '';     // كلمة المرور
     ```

4. **تشغيل المشروع**
   - افتح المتصفح وتوجه إلى رابط المشروع (مثلاً `http://localhost/Quran-Researcher`).
